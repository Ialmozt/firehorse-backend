## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### ПРОБЛЕМА 1: ПОДКЛЮЧЕНИЕ К БАЗЕ ДАННЫХ
**Описание:** Не удается подключиться к Supabase PostgreSQL
**Причина:** IPv6 сеть недоступна (2a05:d016:571:a412:676c:e5d3:b38f:8c5e)
**Влияние:** Worker не может обрабатывать задания, API показывает 'database: disconnected'
**Приоритет:** ВЫСОКИЙ (блокирует основную функциональность)

### ПРОБЛЕМА 2: ОШИБКИ АУТЕНТИФИКАЦИИ WORKER
**Описание:** Worker получает 401 Unauthorized от Supabase
**Причина:** Возможная проблема с service role key или RLS политиками
**Влияние:** Worker не может читать глубину очереди или обрабатывать заказы
**Приоритет:** ВЫСОКИЙ (блокирует обработку заказов)

### ПРОБЛЕМА 3: PROMETHEUS КОНТЕЙНЕР ПЕРЕЗАГРУЖАЕТСЯ
**Описание:** Контейнер Prometheus в цикле перезагрузки

**Влияние:** Сбор метрик может быть неполным
**Приоритет:** СРЕДНИЙ (влияет на мониторинг)

### ПРОБЛЕМА 4: FRONTEND DEV SERVER НЕ ЗАПУЩЕН
